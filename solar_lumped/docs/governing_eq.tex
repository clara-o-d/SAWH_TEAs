\section*{Reference and scope}

This document describes the lumped system + techno-economic model implemented in
\code{solar\_lumped}, following Wilson \& D\'{i}az-Mar\'{i}n \textit{Device} (2025) Eqs.~1--6
and Note~S1 (COMSOL Table~S3 parameters) for the physics, and the package's own
\code{economics/} module for cost. The system is a single hydrogel bed that alternates
between open \emph{absorption} (night) and sealed \emph{desorption} (day) half-cycles. This
is the default (\code{desorption\_solver="quasi\_steady"}) configuration; one alternate
exists in code but is out of scope here: \code{segregated} / \code{coupled\_bdf} desorption
integrators, which trade the quasi-steady algebraic thermal solve for COMSOL-mimicking or
fully transient alternatives (\code{system\_config.py}).

\textbf{Base case is Case 2, not Wilson's original paper physics.} As of 2026-07,
\code{SystemConfig.thermal\_params()} -- the physics every plain \code{SystemConfig()} call
gets unless it explicitly overrides \code{thermal=} -- defaults to real absorber/glass IR
emissivities ($\varepsilon_{abs,ir}=0.05$, $\varepsilon_{gl,ir}=0.95$, the "selective surface"
variant, Case~2 in \code{sawh\_bayesopt.design\_space.CASE\_EPS\_IR}) rather than Wilson's
original blackbody/cavity approximation (Case~1). Every equation, assumption, and default value
below describes Case~2 unless stated otherwise. Case~1 (Wilson's exact paper physics) remains
reachable via an explicit \code{SystemThermalParams(eps\_abs\_ir=1.0, eps\_glass\_ir=1.0)} (or
the equivalent \code{eps\_abs\_ir=eps\_glass\_ir=None}, still numerically identical -- see
Section~\ref{sec:radiative}) override, and is exactly what the paper-reproduction scripts under
\code{analysis/paper\_recreation/wilson/} use -- those scripts build their own
\code{SystemThermalParams} directly rather than going through
\code{SystemConfig.thermal\_params()}, so they are unaffected by this default and continue to
reproduce Wilson's digitized figures under Case~1. Case~3 (idealized optical-material limits,
$\varepsilon_{abs,ir}=\varepsilon_{gl,ir}=0.0$) is a third explicit sensitivity variant, also not
the default.

\textbf{Subscripts:} $g$ = hydrogel; $abs$ = solar absorber; $gl$ = cover glass; $cond$ =
aluminum condenser; $amb$ = ambient.

\section{Model design}

\subsection{System overview}

A footprint-area system stacks (top to bottom, day-side up): cover glass $\to$ air/insulation
gap $\to$ solar absorber (aluminum) $\to$ hydrogel-salt composite bed $\to$ vapor gap $\to$
aluminum condenser (finned, ambient-cooled). All balances are per unit footprint area
(\si{\metre\squared}) unless noted. During \textbf{desorption} (daytime), the chamber is
sealed: solar radiation heats the absorber, which conducts heat into the gel; the gel desorbs
water vapor across the vapor gap to the cooler condenser, where it condenses and is collected.
During \textbf{absorption} (nighttime), the chamber is opened to ambient air; the gel re-hydrates
by uptake from ambient humidity, with no solar input and no condenser dynamics. An optional
uncovered variant (\code{has\_glass=False}) removes the glass/insulation-gap stack entirely and
radiates the absorber directly to a sky/ambient sink.

\textbf{Absorption phase ODEs:} $\dot{c}_w$, $\dot{H}$ with $Q_{solar}=0$, $\dot{m}_{des}=0$,
$\dot{T}_{cond}=0$. \textbf{Desorption phase ODEs:} $\dot{c}_w$, $\dot{H}$, $\dot{T}_{cond}$
with $T_g$, $T_{abs}$, $T_{gl}$ from the coupled thermal solve.

\subsection{Daily cycle structure}

One simulated day is one absorption half-cycle followed by one desorption half-cycle, gel
state carried forward between them. The absorption/desorption split follows the forcing
weather profile's own real day/night boundary (solar-radiation threshold crossing, so the two
halves are not forced to equal length) in \code{real}/replay weather modes; the
\code{baseline} synthetic-profile mode instead defaults to a fixed
\SI{12}{\hour}/\SI{12}{\hour} split (\code{weather/profiles.py::PHASE\_HOURS}) so that
single-axis parameter sweeps hold the forcing schedule constant. Multi-day runs either warm up
for a fixed cycle count or use Aitken $\Delta^2$ extrapolation (\code{find\_cyclic\_state}) to
locate the true steady periodic post-desorption $(c_w, H)$ state before reporting a single
representative day.

\section{Physics model assumptions}

\begin{itemize}
\item \textbf{Lumped / 0-D:} the gel, absorber, glass, and condenser are each a single uniform
temperature node per footprint area; no through-thickness gradients are resolved.
\item \textbf{Quasi-steady thermal solve during desorption:} $T_g$, $T_{abs}$, $T_{gl}$ are found
by root-finding the steady residual form of Eqs.~1, 3, 4 at every ODE evaluation (assumes the
thermal response is fast relative to the hydration/mass-transfer timescale). Only $T_{cond}$
carries real thermal inertia (finite aluminum slab thermal mass) during desorption.
\item \textbf{Absorption thermal shortcut:} during absorption, $T_g = T_{abs} = T_{gl} = T_{amb}$
is assumed outright (fast gel thermal storage, \code{coupled\_dynamics.py} Note~S1 Eq.~S1)
rather than solved from Eqs.~1/3/4 -- there is no solar input and no condenser coupling to
balance against.
\item \textbf{Radiative exchange (base case, Case~2 "selective surface"):}
absorber$\leftrightarrow$glass and glass$\leftrightarrow$ambient exchange use real IR
emissivities $\varepsilon_{abs,ir}=0.05$, $\varepsilon_{gl,ir}=0.95$,
not Wilson's typeset Eqs.~3--4 blackbody/cavity approximation ($\varepsilon=1$). Setting both to
$1.0$ (Case~1) reproduces Wilson's original paper physics exactly; setting both to $0.0$ (Case~3)
gives the idealized optical-material-limits sensitivity variant. See
Section~\ref{sec:radiative}.
\item \textbf{Water inventory basis:} $c_w$ and $H$ are tracked as separate states, but the
sorbate mass used for activity/uptake calculations is referenced to the fixed fabrication
thickness $H_0$, not the swollen $H(t)$ -- swelling only feeds back into vapor-gap convection
($L_g-H$) and gel--absorber conductance ($H/k_{gel}$). This avoids double-counting dilution (see
\code{salt\_properties.py::pam\_licl\_gravimetric\_uptake\_g\_g}).
\item \textbf{Water activity:} brine activity from the Conde (2004) correlation, in both
half-cycles and for every salt. Water in the gel has the chemical potential of pure water plus
$RT\ln(x_w\gamma_w)$, so the salt-in-water activity model \emph{is} the sorption isotherm. An
earlier version capped absorption with the measured PAM--LiCl DVS isotherm, $a_w =
\max(a_{w,brine}, a_{w,DVS})$; that cap contradicted the activity model between RH 0.73 and 0.90
(cutting equilibrium uptake up to 24\%) and then switched itself off above RH 0.90 where the
measured curve ran out of data, producing a slope discontinuity in the wettest climates. It also
applied to LiCl alone, putting a cliff at the pure-LiCl corner of the blend simplex.
\item \textbf{Mass-transfer coefficient:} absorption uses a fixed empirical open-chamber
convection coefficient $g_{chamber}$; desorption derives $g$ from the vapor-gap natural-convection
$h_{conv,g}$ (the stratified-cavity correlation below, \emph{not} Hollands) via a
Lewis-number-unity heat/mass analogy (Note~S1 Eq.~S5). No forced convection is modeled in
either phase.
\item \textbf{Self-consistent desorption coupling:} $\dot{m}_{des}$ is found as the root of
$\dot{m}_{calc}(\dot{m}_{des}) - \dot{m}_{des} = 0$ (Brent's method) so that the gel heat balance
(Eq.~1) and the mass-transfer equations (Eqs.~5--6) agree on the same rate at every step.
Under the instant-kinetics ideal case this inverts -- $\dot{m}_{des}$ is set by the energy
balance and the rate law is replaced by an equilibrium constraint; see
Section~\ref{sec:ideal}.
\item \textbf{Scope:} default salt is LiCl with a hydrogel sorbent. A MOF-sorbent path and three
additional deliquescent salts (blendable via ZSR mixing) exist in code with their own property
tables but are not documented further here, except to note that a blend's deliquescence RH (the
water-activity floor of its brine window, \code{deliquescence\_rh}) is temperature-dependent for
LiCl/CaCl$_2$ and is evaluated at the gel's actual temperature bucket, not a fixed 25\,\si{\celsius}
-- a fixed-25\,\si{\celsius} floor understated $a_w$ by 0.055 at 80\,\si{\celsius} for LiCl, a
$\sim$30$\times$ error in the desorption driving force $(C_R-a_w)$ for a gel dried past
saturation.
\item \textbf{Initial condition:} $c_w$ initializes at equilibrium with the $\sim$\SI{20}{\percent}
RH ambient the gel is fabricated at (brine activity), unless a cyclic steady-state or explicit
override is requested instead.
\end{itemize}

\section{Thermal balances (Wilson Eqs.~1, 3, 4)}\label{sec:radiative}

During each integration step the gel, absorber, and glass temperatures satisfy the steady
residual form (Eqs.~1, 3, 4 set to zero):

\begin{equation}
U_{gel}(T_{abs} - T_g)
= h_{conv,g}(T_g - T_{cond})
+ \dot{m}_{des}\,h_{des}
+ \varepsilon_{gc}\sigma(T_g^4 - T_{cond}^4)
\label{eq:gel}
\end{equation}

\begin{equation}
k_{air}\frac{T_{abs} - T_{gl}}{L_{ins}}
+ \varepsilon_{ag}\sigma(T_{abs}^4 - T_{gl}^4)
= h_{amb}(T_{gl} - T_{amb})
+ \varepsilon_{ga}\sigma(T_{gl}^4 - T_{amb}^4)
\label{eq:glass}
\end{equation}

\begin{equation}
\varepsilon_{abs}\,\tau_{glass}\,Q_{solar}
= k_{air}\frac{T_{abs} - T_{gl}}{L_{ins}}
+ \varepsilon_{ag}\sigma(T_{abs}^4 - T_{gl}^4)
+ U_{gel}(T_{abs} - T_g)
\label{eq:absorber}
\end{equation}

In the uncovered variant (\code{has\_glass=False}), Eqs.~\eqref{eq:glass}--\eqref{eq:absorber}
collapse to a single absorber-to-ambient balance $\varepsilon_{abs}Q_{solar} =
h_{amb}(T_{abs}-T_{amb}) + \varepsilon_{abs}\sigma(T_{abs}^4 - T_{amb}^4) + U_{gel}(T_{abs}-T_g)$
with $T_{gl} \equiv T_{amb}$.

$L_{ins}$ here is Wilson's typeset Eq.~3/4 $L_c$ (the 5~mm absorber--glass insulating air gap,
Table~S3); this document renames it to avoid confusion with the unrelated aluminum condenser/gel-backing
plate thickness (also 5~mm in Table~S3), which the codebase also happens to call $L_c$ (\code{L\_C\_M}).
Same value, same equation, different symbol.

\textbf{Correlations (Note~S1):}
\begin{itemize}
\item $h_{conv,g} = \mathrm{Nu}\,k_{air}/(L_g - H)$ across the vapor gap (Note~S1 Eq.~S4),
tilt-dependent. Note~S1 cites Hollands et al.\ (1976) for $\mathrm{Nu}$, but Hollands is a
heated-from-\emph{below} correlation and Wilson's stack puts the hydrogel \emph{above} a
downward-facing finned condenser, so during desorption the cavity is heated from above:
stably stratified, with no Rayleigh--B\'enard onset. This model therefore uses ISO 15099
\S5.3.3.5 for the inclined downward-facing cavity,
\begin{equation}
\mathrm{Nu} = 1 + [\mathrm{Nu}_v - 1]\sin\vartheta, \quad \vartheta = 180^\circ - \theta,
\label{eq:nugap}
\end{equation}
with $\mathrm{Nu}_v$ from ISO 15099 Eqs.~48--52 at aspect ratio $H_{cav}/(L_g - H)$. Hollands
Eq.~S3 is retained \emph{only} for the inverted iterate ($T_{cond} > T_{gel}$), which a
bottom-heated layer genuinely is; \code{solve\_steady\_thermal} probes such pairs on
$\sim$25\% of calls, but no converged desorption state is one. Hollands over-predicts gap
$\mathrm{Nu}$ by $\sim$1.8--2$\times$ here (4.79 vs.\ 2.65 at the baseline desorption peak).
See \code{physics.py::vapor\_gap\_h\_conv\_w\_m2\_k}.
\item \textbf{Tilt and solar gain (POA, on by default).} Wilson's Eq.~4 drives the
absorber with the site's \emph{horizontal} irradiance (GHI), which leaves the tilt $\theta$
entering the model \emph{only} through Eq.~\eqref{eq:nugap} -- the vapor gap is the one
tilt-dependent correlation in the stack, since both glazing cavities are modelled as pure
conduction $k_{air}\Delta T/L_{ins}$. Tilt then changes internal natural convection but not
the energy the device collects, which makes $\theta$ monotone in the wrong direction for a
solar collector. \code{profile\_from\_day\_df} therefore defaults to
\code{poa\_tilt\_deg = POA\_DEFAULT\_TILT\_DEG} ($=\theta$), transposing GHI onto the tilted
aperture via the Erbs et al.\ (1982) diffuse-fraction split plus Liu \& Jordan isotropic-sky
transposition,
\begin{equation}
Q_{POA} = DNI\max(0,\cos\theta_{AOI}) + DHI\,\frac{1+\cos\beta}{2}
+ GHI\,\rho_g\,\frac{1-\cos\beta}{2},
\label{eq:poa}
\end{equation}
so a single $\theta$ trades solar gain against gap convection simultaneously. At
$\beta = 0$ Eq.~\eqref{eq:poa} reduces exactly to $Q_{POA} = GHI$. Pass
\code{poa\_tilt\_deg=None} for raw GHI; the Wilson recreation does exactly that, because the
paper's field tests were driven by measured horizontal flux with no transposition. The
day/night phase split stays keyed on GHI either way, so phase boundaries are unaffected. Example (Cambridge, summer solstice, 4\,mm gel):
with GHI the mean flux is 595\,W/m$^2$ at every tilt and yield rises monotonically
$0^\circ \to 60^\circ$ (1.882 $\to$ 1.904\,kg/m$^2$) purely via gap convection; with POA the
flux varies (595 $\to$ 449\,W/m$^2$) and yield acquires an interior optimum near
$15^\circ$ (1.927\,kg/m$^2$).
\item $\varepsilon_{gc} = 1/(1/\varepsilon_{gel} + 1/\varepsilon_{Al} - 1)$: parallel-plate
radiative exchange (Eq.~S2).
\item $U_{gel}$: series-resistance gel--absorber conductance (updated from the single-layer
approximation in earlier drafts of this document to match \code{table\_s3.py::u\_gel\_w\_m2\_k}):
\begin{equation}
\frac{1}{U_{gel}} = \frac{L_{Al}}{k_{Al}} + \frac{L_{silicone}}{k_{silicone}} + \frac{H(t)}{k_{gel}}
\label{eq:ugel}
\end{equation}
(aluminum backing + silicone bonding layer + hydrogel conduction in series; $H$ floored at
$H_0/4$ to avoid a singular resistance).
\item $\varepsilon_{ag}, \varepsilon_{ga}$ (base case, Case~2): $\varepsilon_{ag} =
\mathrm{parallel\_plate\_emissivity}(\varepsilon_{abs,ir}, \varepsilon_{gl,ir}) =
1/(1/0.05 + 1/0.95 - 1) \approx 0.0508$ (absorber$\to$glass, same parallel-plate formula as
$\varepsilon_{gc}$ above); $\varepsilon_{ga} = \varepsilon_{gl,ir} = 0.95$ directly (glass radiates
to ambient/sky, not a cavity). Case~1 ($\varepsilon_{abs,ir}=\varepsilon_{gl,ir}=1.0$) collapses
both to $1.0$, reproducing the blackbody base model exactly; Case~3 (both $0.0$) collapses both
to $0.0$ (no net IR exchange).
\item Absorption: $Q_{solar}=0$; desorption: $Q_{solar}\ge 0$ from the weather profile (or a
fixed baseline value for controlled sweeps).
\end{itemize}

\section{Condenser energy balance (Wilson Eq.~2, transient)}

During desorption only:
\begin{equation}
(\rho c_p L)_{cond}\,\frac{dT_{cond}}{dt}
= h_{conv,g}(T_g - T_{cond})
+ \dot{m}_{des}\,h_{fg}
+ \varepsilon_{gc}\sigma(T_g^4 - T_{cond}^4)
- A_r\,h_{amb}(T_{cond} - T_{amb})
\label{eq:condenser}
\end{equation}

where $A_r$ is the fin area ratio and $h_{conv,cond} = A_r\,h_{amb}$ (or $A_r\,h_{amb,cond}$ when a
separate fan-forced condenser convection coefficient is supplied).

\section{Mass transport (Wilson Eqs.~5--6)}

\begin{equation}
\frac{dc_w}{dt}
= \frac{g}{H_0}\,\frac{P_{sat}(T_g)}{RT_g}\,(C_R - a_w)
\label{eq:dcw}
\end{equation}

\begin{equation}
\frac{dH}{dt}
= g\,\frac{MW_{w}}{\rho_{sol}}\,\frac{P_{sat}(T_g)}{RT_g}\,(C_R - a_w)
\label{eq:dH}
\end{equation}
Wilson's Eq.~6 as printed omits the $g$ prefactor, but the bare product
$\frac{MW_w}{\rho_{sol}}\frac{P_{sat}}{RT_g}$ is dimensionless (m$^3$/mol $\times$ mol/m$^3$), so
$dH/dt$ as printed cannot carry units of m/s. Including $g$ (same mass-transfer coefficient as
Eq.~\eqref{eq:dcw}) is required both for dimensional consistency and to match the desorption
mass-rate identity $\dot{m}_{des} = -\rho_{sol}A_c\,dH/dt$ used elsewhere in the paper against the
flux-based $\dot{m}_{des} = MW_w\,g\,\frac{P_{sat}}{RT_g}(C_R-a_w)$. This implementation therefore
keeps the $g$ factor.

\textbf{Concentration ratio $C_R$:}
\begin{align}
C_R &= RH_{amb} && \text{(absorption, open chamber)} \\
C_R &= \frac{P_{sat}(T_{cond})}{P_{sat}(T_g)}\,\frac{T_g + 273.15}{T_{cond} + 273.15}
&& \text{(desorption, vapor gap)}
\end{align}

\textbf{Mass-transfer coefficient $g$:}
\begin{align}
g &= g_{chamber} && \text{(absorption)} \\
g &= h_{conv,g}\,\frac{D_{air}}{k_{air}} && \text{(desorption; Lewis-number analogy, Note~S1 Eq.~S5)}
\end{align}

\textbf{Water activity $a_w$:} brine activity from salt thermodynamics, in both half-cycles.
No measured-uptake cap -- see the note above.

\textbf{Saturation vapor pressure $P_{sat}(T)$:} Conde (2004) Saul--Wagner correlation, with a
Tetens-equation fallback if the primary correlation is non-finite
(\code{salt\_properties.py::saturation\_vapor\_pressure\_pa}).

\textbf{Desorption mass flux from gel inventory:}
\begin{equation}
\dot{m}_{des} = MW_w\,\bigl(-\dot{c}_w\,H - c_w\,\dot{H}\bigr), \qquad \dot{m}_{des} \ge 0
\label{eq:mdes}
\end{equation}

\section{Thermal--mass coupling constraint}

During desorption, $\dot{m}_{des}$ in Eq.~\eqref{eq:gel} must equal the flux implied by
Eqs.~\eqref{eq:dcw}--\eqref{eq:mdes}. The implementation finds $\dot{m}_{des}$ as the root of
$f(\dot{m}_{des}) = \dot{m}_{calc}(\dot{m}_{des}) - \dot{m}_{des} = 0$ (Brent's method), ensuring
Eqs.~1 and 5--6 are self-consistent at each ODE evaluation.

\section{Ideal-case variants: instant kinetics and a perfect condenser}\label{sec:ideal}

Two idealizations sit on top of the physics above, each removing one loss mechanism to
bound what the device could do if that mechanism were perfect. Both are switches on
\code{SystemConfig}, off by default, and both are upper bounds rather than designs.

\subsection{Perfect condenser}

\code{SystemConfig(condenser\_tracks\_ambient=True)}. The limit of infinite condenser cooling capacity: $T_{cond} = T_{amb}$ at every instant,
so the condenser never warms under its own latent load. Eq.~\eqref{eq:condenser} is
dropped and $T_{cond}$ ceases to be a state; everything downstream that reads $T_{cond}$
(notably $C_R$) reads $T_{amb}$ instead. This raises the desorption driving force
throughout the day.

\subsection{Instant kinetics: the \texorpdfstring{$g \to \infty$}{g to infinity} limit as a constraint}

\code{SystemConfig(instant\_equilibrium=True)}. The ideal-kinetics limit is \emph{not} "a very large $g$" -- it is the statement that the
gel surface sits at local equilibrium with whatever it is exchanging vapour with, so
Eq.~\eqref{eq:dcw}'s driving force is identically zero:
\begin{equation}
a_w(c_w, T_g) = C_R
\label{eq:localeq}
\end{equation}
Imposing Eq.~\eqref{eq:localeq} directly, rather than approaching it by inflating $g$, is
what makes this case tractable; the numerical argument is in Section~\ref{sec:penalty}.
Because it is a statement about kinetics, it also bypasses the \SI{7}{\milli\metre}
vapour-gap transport cutoff -- that cutoff is itself a mass-transfer limit and has no
place in a $g \to \infty$ bound.

\textbf{Desorption: which variable is unknown changes.} With $C_R$ fixed at the desorption
form, Eq.~\eqref{eq:localeq} determines the gel temperature outright,
\begin{equation}
T_g = T_{eq}(c_w, T_{cond}) : \quad
a_w(c_w, T_{eq}) = \frac{P_{sat}(T_{cond})}{P_{sat}(T_{eq})}\,\frac{T_{eq}+273.15}{T_{cond}+273.15}
\label{eq:teq}
\end{equation}
which has a unique root above $T_{cond}$: $a_w$ varies weakly with temperature while $C_R$
falls as $P_{sat}(T_g)$ grows, and at $T_g=T_{cond}$ exactly, $C_R = 1 \ge a_w$
(\code{physics.equilibrium\_t\_gel\_desorption\_c}). $\dot{m}_{des}$ is then no longer given
by a rate law -- it is promoted to an unknown and set by whatever the quasi-steady thermal
balances can pay $h_{des}$ for at that $T_g$. Desorption becomes energy-limited by
construction, which is what the ideal case is meant to represent. The loading rate follows
by inverting the flux instead of from Eq.~\eqref{eq:dcw}, whose driving force is now zero:
\begin{equation}
\frac{dc_w}{dt} = -\frac{\dot{m}_{des}}{MW_w\,H_0}, \qquad
\frac{dH}{dt} = \frac{dc_w}{dt}\,\frac{MW_w H_0}{\rho_{sol}}
\label{eq:dcw-ideal}
\end{equation}

\textbf{Complementarity: the constraint is not always active.} Eq.~\eqref{eq:localeq} holds
only where desorption is actually possible; otherwise $\dot{m}_{des} = 0$ and the gel sits
off the isotherm. Three switches, checked before the solve:
\begin{itemize}
\item $c_w \le c_{w,\min}$ -- at the hydrate floor there is no removable water left,
whatever the energy available.
\item $T_{eq}$ has no root (no bracket in $[T_{cond}, T_{cond}+200\,\si{\celsius}]$), e.g.\ a
gel with no water to have an activity.
\item Carrying \emph{no} latent load the gel still cannot reach $T_{eq}$, i.e.\ the driving
force is already non-positive at $\dot{m}_{des}=0$. The energy is not there. This is the
same physical branch as the finite-$g$ path's $\dot{m}_{calc}(0)\le 0$ short-circuit,
reached without consulting a rate law.
\end{itemize}
On any of the three, the thermal state is the one solved at $\dot{m}_{des}=0$.

\textbf{Absorption: no ODE at all.} Here $T_g = T_{amb}$ (Note~S1 Eq.~S1), so nothing on
this half-cycle is heat-limited, and $C_R = RH_{amb}$. The forcing weather is
piecewise-constant on the profile step $dt$, so instant kinetics means the gel sits at the
equilibrium loading of the \emph{current} interval, always: the exact trajectory is a
staircase and the solution is one isotherm inversion per interval
(\code{equilibrium\_c\_w\_absorption}), with $H$ following by
Eq.~\eqref{eq:dcw-ideal}'s identity accumulated interval by interval so the swelling clamps
bite where they would have during integration.

\textbf{Two algebraic realizations of the same constraint.} The CPU path pins $T_g = T_{eq}$
and solves the scalar root $T_g(\dot{m}_{des}) - T_{eq} = 0$ in $\dot{m}_{des}$ (Brent);
the JAX path instead solves one joint $4\times4$ Newton system in
$(T_g, T_{abs}, T_{gl}, \dot{m}_{des})$ with Eq.~\eqref{eq:localeq} as its fourth residual,
which avoids nesting a bracket around a Newton solve on GPU. Both impose the same
constraint and are pinned against each other to \num{5e-4} relative on annual yield
(\code{tests/test\_cpu\_jax\_parity.py}).

\subsection{Why not simply inflate \texorpdfstring{$g$}{g}}\label{sec:penalty}

The earlier implementation approximated the limit by scaling $g$ by $10^5$ until
Eq.~\eqref{eq:dcw}'s residual was negligible -- a penalty method for an algebraic
constraint. It converges to the same answer and is retained solely as the independent
reference the constraint route is pinned against (\code{tests/test\_local\_equilibrium.py},
at $g\times10^6$), but it is unusable in production for two reasons:
\begin{itemize}
\item \textbf{Stiffness.} $\dot{c}_w$ acquires a slope of order $g$ whenever $c_w$ sits even
slightly off the isotherm, forcing tiny explicit steps: the absorption half-cycle alone
needed $>16{,}384$ steps per day in the JAX backend and silently truncated when it ran out.
The desorption root $\dot{m}_{calc}(\dot{m}_{des}) - \dot{m}_{des}$ was near-vertical for the
same reason, ill-conditioned enough to need a "Brent returned the jump, not the root"
fallback. Under the constraint, $T_g(\dot{m}_{des}) - T_{eq}$ is a well-scaled monotone root
in kelvin and the remaining ODE moves at the rate energy permits.
\item \textbf{It is a tuned parameter, not a limit.} The answer depends on the scale chosen
(a residual bias of order \SI{0.1}{\percent} at $10^5$); under the constraint the scale
does not exist.
\end{itemize}
Cost: the ideal scenarios went from $\sim$\num{50}$\times$ the per-instance-day cost of
finite $g$ to slightly \emph{less} than it, since their absorption half needs no integrator.

\subsection{Scenario matrix}

\section{Constraints and cycle-level outputs}

\begin{itemize}
\item $c_w \in [c_{w,\min}, c_{w,\max}]$; rates clipped at bounds. Both bounds are physical, not
tuning constants, and are computed per salt/blend and salt loading $c_s$ rather than shared global
values: $c_{w,\min} = n_{hydrate}\,c_s$ is the water content of the lowest hydrate stable at
desorption temperatures (\code{hydrate\_floor\_c\_w}) -- below it the remaining water is
crystal-bound and removing it is a dehydration reaction Eq.~\eqref{eq:dcw} does not model;
$c_{w,\max}$ is the equilibrium $c_w$ at a shared dilution-cap water activity
(\code{dilution\_ceiling\_c\_w}, \code{Dilution cap (maximum water activity)} row) -- past it
$a_w\to 1$, $c_w$ diverges, and the $a_w \to$ brine-fraction inversion loses conditioning.
\code{SystemConfig(c\_w\_floor\_mode="drh")} swaps the lower bound for the equilibrium $c_w$ at
the salt's deliquescence RH (\code{drh\_floor\_c\_w}) -- i.e.\ stop where the brine saturates
rather than where it crystallizes. That is the conservative choice: a saturated LiCl brine still
holds $\approx$2.78 H$_2$O per LiCl against 1 in the monohydrate, so it ends desorption earlier
and yields less (baseline profile: 2.30 vs.\ \SI{2.61}{\kilo\gram\per\square\metre\per day}).
\item $H \ge H_0$; swelling allowed in absorption ($\dot{H}\ge 0$ at $H=H_0$); no shrinkage below
$H_0$ in desorption.
\item Desorption: enforce $\dot{c}_w \le 0$, $\dot{H} \le 0$.
\item \emph{No} sub-\SI{7}{\milli\metre} transport cutoff. Wilson sets $g \to 0$ below a
\SI{7}{\milli\metre} gap $L_g - H$, reading Hollands' $\mathrm{Ra}_{crit} = 1708$ onset
(under which $\mathrm{Nu} \equiv 1$) as inhibited transport. The stratified correlation
Eq.~\eqref{eq:nugap} has no such onset -- a layer heated from above never goes
Rayleigh--B\'enard -- so $\mathrm{Nu}$ decays smoothly to 1, and $\mathrm{Sh} = \mathrm{Nu} =
1$ is \emph{diffusion}, which over a \SI{5}{\milli\metre} path is $\sim3\times$ the $g$ of
the \SI{36}{\milli\metre} baseline rather than zero. Small gaps still lose, through the
$k/L$ heat leak to the condenser that the thermal balance already carries; the hard wall made
that a step discontinuity that took yield to exactly 0. The gel is kept out of the condenser
by the swelling cap in \code{\_integrate\_absorption}, which is geometry, not a correlation
limit.
\item Initial $c_w$ from fabrication equilibrium RH (brine activity at $H_0$) unless overridden.
\item Daily water yield is the condenser-collected mass over one desorption phase; thermal
efficiency $\eta_{th} = \dot{m}_{water}\,h_{fg} / \int Q_{solar}\,dt$, integrated over the
desorption phase only (blending in the near-zero-solar absorption phase would dilute the ratio
without adding real signal).
\end{itemize}

\section{Economics model assumptions}

\begin{itemize}
\item \textbf{LCOW} is a standard fixed-charge-rate techno-economic calculation: annualized cost
divided by annual usable water volume. CAPEX is amortized via a capital recovery factor (CRF) at
a fixed discount rate over a fixed system lifetime -- not a full multi-year cash-flow model with
price escalation.
\item \textbf{NPV / payback} (\code{npv.py}) reuses the same cost components as LCOW, but
restructures CAPEX as an upfront year-0 payment against a level (non-escalating) annual net cash
flow (revenue at an assumed water price, minus OPEX), discounted at the same rate -- a
level-annuity NPV, not a full pro forma.
\item \textbf{CAPEX} is a fixed per-footprint bill of materials (BOM), summed from six line items,
scaled uniformly by a \code{total\_investment\_factor} (contingency / installation multiplier
that is easy to sweep even though the underlying line items themselves are not).
\item \textbf{Maintenance} is a fixed fraction of the bare system BOM cost per year (not the
TIC-inflated CAPEX, so it is unaffected by the total investment factor) -- not tied to any
modeled failure or service-call process.
\item \textbf{Sorbent replacement:} the hydrogel is replaced on a fixed interval
(\code{hydrogel\_lifetime\_years}); its replacement cost is the dry composite mass per footprint
area times a blended cost per kg. The blend price weights the salt and the polymer sub-mix
(acrylamide/APS/MBA/TEMED) by the salt loading, and separately adds a DI-water term sized by
that water's mass fraction of the whole synthesis batch (Table~S1 recipe) -- not a fixed
per-ingredient cost. MOF sorbent instead uses mass $\times$ price / lifetime directly.
\item \textbf{Utilization factor} is a single multiplicative derating of the physics-simulated
gross annual yield (daily yield $\times$ 365 $\times$ cycles/day), meant to stand in for real-world
downtime / non-ideal weather years -- not a modeled reliability/availability process.
\item \textbf{No energy cost:} the system is passive solar -- no electricity, electric-heat
assist, or per-cycle energy term exists in this package (see Eq.~\eqref{eq:annual-cost}).
\item \textbf{Out of scope:} water transport/distribution, land, installation labor, permitting,
and end-of-life salvage value are not modeled.
\item \textbf{No escalation:} all costs are unescalated real USD (no inflation or fuel/material
price growth curves).
\item \textbf{Water price} (NPV/payback only) is an external scenario input, not derived from any
market model.
\end{itemize}

\section{Economics governing equations}

\textbf{Capital recovery factor:}
\begin{equation}
CRF = \frac{i(1+i)^L}{(1+i)^L - 1}
\label{eq:crf}
\end{equation}
where $i$ is the discount rate and $L$ the system lifetime (years).

\textbf{Sorbent (hydrogel) replacement, annualized:}
\begin{equation}
C_{sorbent} = \frac{c_{gel}\,m_{dry}}{L_{gel}}, \qquad
c_{gel} = \frac{c_{salt}\,SL + c_{polymer}}{1 + SL} + \frac{\phi_{water}}{1-\phi_{water}}\,c_{water}
\label{eq:sorbent}
\end{equation}
\begin{equation}
c_{polymer} = \frac{\displaystyle\sum_{k \in \{AM,APS,MBA,TEMED\}} \phi_k\,c_k}
{\displaystyle\sum_{k \in \{AM,APS,MBA,TEMED\}} \phi_k}
\label{eq:polymer-blend}
\end{equation}
where $m_{dry} = H_0\,\rho_{gel,dry}$ is the dry (solids-only) composite mass per footprint area.
$H_0$ is the \code{Hydrogel reference thickness (H0)} row (\SI{4}{\milli\metre}, Physics sheet).
$\rho_{gel,dry}$ is \emph{not} the Table~S3 \code{Composite (hydrogel) density at 20\% RH
(rho\_gel)} row (\SI{1250.2}{\kilo\gram\per\cubic\metre}) directly -- that density is measured on
the composite already equilibrated at \SI{20}{\percent} RH, whose measured moisture content is
$\approx$\SI{126}{\percent} by dry mass, i.e.\ using it as-is would overstate the purchased
dry-solids mass (and hence $C_{sorbent}$) by $1+u_{20} \approx 2.26\times$. That single measured
number is now the \code{Dry composite density (rho\_dry)} Physics row -- a mass calibration, not a
sorption model. Instead
$\rho_{gel,dry} = \rho_{gel}/(1+u_{20})$
(\code{physics.py::DRY\_COMPOSITE\_DENSITY\_KG\_M3}, $\approx$\SI{553}{\kilo\gram\per\cubic\metre}),
the same dry-basis density physics.py already uses for its own gravimetric-uptake and
initial-$c_w$ calculations -- \code{economics.py::dry\_composite\_mass\_kg} now imports it rather
than reading \code{rho\_gel} directly, to keep the two files' notions of "dry mass" consistent.
$\phi_{water}$ below is a separate quantity: the DI water mixed in during synthesis (Table~S1),
not water later absorbed from ambient. $SL$ is the
salt loading, $L_{gel}$ is the hydrogel replacement interval (years), $\phi_k$ is ingredient
$k$'s mass fraction in the whole synthesis batch (Table~S1 recipe: AM, APS, MBA, TEMED, salt, and
DI water), and $c_k$ its catalog price. $c_{polymer}$ (Eq.~\eqref{eq:polymer-blend}) is the
acrylamide/APS/MBA/TEMED sub-mix price, mass-fraction-weighted and renormalized over just those
four ingredients (their $\phi_k$ do not sum to 1 alone -- the batch also contains salt and water).
The $\phi_{water}/(1-\phi_{water})$ term converts the DI-water mass fraction of the whole batch
into a ratio against the batch's dry (non-water) mass, since $m_{dry}$ already excludes water.
The cost breakdown (\code{lcow\_cost\_breakdown\_from\_daily\_yield}) further splits
$c_{polymer}/(1+SL)$ back into its four per-ingredient terms
$\frac{\phi_k}{\sum_k \phi_k}\,\frac{c_k}{1+SL}$ for reporting. (MOF sorbent:
$C_{sorbent} = m_{MOF}\,c_{MOF} / L_{gel}$ directly.)

\textbf{Annualized system cost:}
\begin{equation}
C_{annual} = CRF \cdot f_{inv}\,C_{system} + C_{sorbent} + f_{maint}\,C_{system}
\label{eq:annual-cost}
\end{equation}
where $C_{system} = \sum_j C_{BOM,j}$ (six BOM line items),
$f_{inv}$ is the total investment factor, and $f_{maint}$ the maintenance cost fraction.

\textbf{No purchased-energy term:} this system is passive solar, so $C_{annual}$ has no
electricity, electric-heat-assist, or per-extra-cycle energy term at all --
\code{LCOEconomicParams} carries no \code{electricity\_price\_usd\_per\_kwh},
\code{desorption\_hours\_per\_day}, or \code{max\_electric\_heat\_w\_per\_m2} field. Those
knobs previously existed but were provably inert: the electricity cost was
$p_{elec}\,\dot{Q}_{elec}\,t_{des}\cdot 365/1000$ and $\dot{Q}_{elec}$ was hard-zero on
every solar code path, so LCOW was bit-identical for any electricity price or desorption
duration (verified: \$0/kWh through \$100/kWh all give the same LCOW to the last digit).
Multi-cycle operation and supplemental/parasitic electric loads are modelled in the
\code{waste\_heat} package, which is where those terms belong.

\textbf{LCOW:}
\begin{equation}
LCOW = \frac{C_{annual}}{f_{util}\left(\dfrac{365\cdot n_{cyc}\cdot Y_{daily}}{\rho_w}\right)}
\label{eq:lcow}
\end{equation}
where $Y_{daily}$ is the simulated daily water yield (kg/m$^2$), $n_{cyc}$ the number of
half-cycles per day, $\rho_w$ the density of water (kg/m$^3$), and $f_{util}$ the utilization
factor. The cost breakdown (\code{lcow\_cost\_breakdown\_from\_daily\_yield}) reports each term
of Eq.~\eqref{eq:annual-cost} individually, divided by the same denominator, so CAPEX / sorbent /
maintenance / energy segments sum exactly to $LCOW$.

\textbf{Yes, hydrogel lifetime is in LCOW:} $L_{gel}$ (\code{hydrogel\_lifetime\_years}) enters
through $C_{sorbent}$ (Eq.~\eqref{eq:sorbent}), which is a summand of $C_{annual}$
(Eq.~\eqref{eq:annual-cost}), the numerator of Eq.~\eqref{eq:lcow}. A shorter $L_{gel}$
(more frequent hydrogel replacement) raises $C_{sorbent}$ and therefore raises LCOW, all else
equal; it does not otherwise affect system physics or yield -- \code{lcow\_from\_daily\_yield}
(\code{economics.py::\_sorbent\_replacement\_annual\_usd}) is the code path.

\textbf{NPV and payback:}
\begin{align}
NPV &= -f_{inv}\,C_{system} + \left(R_{annual} - OPEX_{annual}\right)\cdot
\frac{1-(1+i)^{-L}}{i}
\label{eq:npv} \\
R_{annual} &= f_{util}\left(\frac{365\cdot n_{cyc}\cdot Y_{daily}}{\rho_w}\right) p_{water}
\label{eq:revenue}
\end{align}
where $p_{water}$ is the assumed water sale price (USD/m$^3$) and $OPEX_{annual}$ is
Eq.~\eqref{eq:annual-cost} without the CAPEX/CRF term. Simple payback is
$CAPEX / (R_{annual}-OPEX_{annual})$; discounted payback solves
$1-\left(1 - i\,CAPEX/(R_{annual}-OPEX_{annual})\right) = (1+i)^{-t}$ for $t$
(\code{npv.py::npv\_from\_daily\_yield}).

\section{Integration}

The coupled physics system is integrated with SciPy \code{solve\_ivp} (LSODA, stiff-capable
multistep). State during desorption: $\mathbf{y} = [c_w,\, H,\, T_{cond}]$; during absorption:
$\mathbf{y} = [c_w,\, H]$. LCOW/NPV are evaluated post-hoc from the resulting daily yield -- they
do not feed back into the ODE integration. Water-balance closure (measured yield vs.\ the
inventory drop implied by the states) is checked each desorption solve against a tolerance
(\code{Desorption water-balance closure tolerance}, Physics sheet) and raises if violated --
catching the LSODA step-rejection failure mode where reported yield silently freezes.
