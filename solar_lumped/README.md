# Solar lumped SAWH

Physics-based simulation and LCOW of the passive solar PAM-LiCl hydrogel SAWH device
(Wilson & Díaz-Marín, *Device*, 2025). The repository [README](../README.md#solar-lumped-sawh-solar_lumped)
has the features, how to run it, and the architecture. The governing equations are in
[`docs/governing_eq.tex`](docs/governing_eq.tex).
